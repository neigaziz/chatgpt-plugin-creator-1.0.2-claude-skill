# Delivery contract

1. **Created:** plugin identity/version, actual purpose, selected architecture and implemented use cases.
2. **Downloads:** upload ZIP, editable sources, validation report/test guide, delivered using real host download mechanism.
3. **Validated:** exact commands, pass/fail, archive hash/file count and warnings. Distinguish local checks from actual upload.
4. **Not verified:** account permissions, ChatGPT acceptance, runtime behavior, external tools/auth, semantic tests or public review as applicable.
5. **Use:** choose Upload plugin archive where enabled, select the upload ZIP (not the creator skill/source ZIP), install/enable as prompted, start new conversation, mention @displayName and give a representative prompt/input.
6. **If blocked:** identify specific missing dependency or platform requirement, provide draft materials with explicit status, ask one essential question. Do not label incomplete integration upload-ready.
7. **Next changes:** preserve source, correct actual findings, bump released versions, revalidate complete archive. No installation or publication without separate approval.
